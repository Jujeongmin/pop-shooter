# 진행 시뮬레이터

- `npm run sim` — 현재 표(`src/sim/stageTable.ts`)로 탭 3회/초 플레이어의 진행 시간.
- `npm run sim -- --taps 0` / `--taps 8` — 완전 방치 / 탭 최대.
- `npm run sim -- --fit` — 목표 시간(`balance.ts` `WORLD_END_MIN`·`FIRST_STAGE_MIN`)에 맞춰 보스 체력 표 다시 생성. 총 가격이 표를 참조하므로 몇 번 반복해 수렴(감쇠 = 이전 표와 기하평균). `--fresh` = 처음부터.
- `node tools/sim/check.ts` — 스펙 4.7 범위 검사(0 = 통과). 수렴 반복: `for i in $(seq 12); do npm run sim -- --fit >/dev/null; node tools/sim/check.ts && break; done`

## 방식 (2026-11-11)

보스 체력을 지수 공식 하나로 두면 앞은 몇 분, 뒤는 수십 시간으로 벌어져 맞출 수 없었다(초기 공식: 40스테이지 6분). 그래서 팝배틀 레벨 표처럼 **목표 시간 → 표**: 스테이지마다 시뮬레이터로 그 목표 시각에 깨지는 최대 체력을 이분 탐색한다. 월드 안 가중치 = 1 + 0.15×(번호−1), 대장 ×2. 총 가격 = 기준 스테이지(월드 1: 2·4·6, 월드 2~4: 앞 대장·2·4·6) 체력 × 8.

플레이어 모델: 1초마다 훈련 코인, "늘어나는 DPS ÷ 비용"이 가장 큰 구매(공격력 1 / 공격 속도 1 / 다음 총), 깰 수 있으면 바로 도전, 10분 진전 없으면 환생.
